# TRO Engineering Toolkit

**TRO Engineering Toolkit** adalah aplikasi berbasis Python yang dirancang untuk membantu mahasiswa Teknologi Rekayasa Otomasi melakukan perhitungan dasar teknik elektro dan elektronika.

## Fitur Utama

1. **Kalkulator Hukum Ohm** — menghitung tegangan, arus, dan hambatan.
2. **Kalkulator Daya Listrik** — menghitung daya menggunakan tegangan, arus, dan hambatan.
3. **Kalkulator Pembagi Tegangan** — menghitung tegangan keluaran dari rangkaian pembagi tegangan.
4. **Kalkulator Kode Warna Resistor** — menentukan nilai hambatan dan toleransi resistor 4 gelang.
5. **Validasi Input** — membantu menangani masukan angka yang tidak valid.

## Teknologi

* Python
* Visual Studio Code
* Git dan GitHub

## Cara Menjalankan

1. Pastikan Python sudah terpasang.
2. Clone repositori ini dan buka folder proyek.
3. Jalankan perintah berikut di terminal:

   ```bash
   python main.py
   ```

   Jika perintah tersebut tidak tersedia, coba `python3 main.py` atau `py main.py`, sesuai sistem operasi yang digunakan.
